# 快速开始

> 文档类型：入门索引。

1. 按[本机安装与启动](local-setup.md)准备环境。
2. 按[采集指南](../guides/collection.md)选择网站、目标和内容。
3. 在[浏览器工作区](../guides/browser.md)完成登录与接管。
4. 在[结果管理](../guides/results.md)检查文件和导出。

需要旧命令行时，使用 [CLI 指南](../guides/cli.md)和[原生环境参考](cli-environment.md)，不要把 CLI 全局配置误认为当前任务配置。遇到问题进入[运行排查](../operations/runtime.md)。
