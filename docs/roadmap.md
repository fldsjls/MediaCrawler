# 工作台路线图

本页只描述后续工作；当前实现见[系统总览](/architecture/overview.md)，验收要求见[质量文档](/development/quality.md)，特定阶段的证据见[历史索引](/history/index.md)。

## 优先完成真实平台验收

使用有效目标逐平台验证登录、采集、视频解析和文件输出，记录可用输入、内容类型与失败边界。对页面变化按适配器职责修复，不在公共下载器添加平台特例。

## 书籍网站

当前仅有类型、网站配置和预览。后续需要书籍、卷、章的内容模型，目录发现、正文提取、章节排序、分页与重复识别，以及导出格式和断点边界。目录与正文规则归书籍适配器，文件生成沿用公共结果/导出机制。

## 购物与价格

当前仅有分类、配置和预览，以及 `ProductRecord` / `PriceObservation` 数据契约；没有商品采集或价格监测执行器。

后续需实现商品/SKU 识别、属性归一、价格观察与历史记录，再考虑定时采集和变化提醒。比较必须区分商品、SKU、币种和价格口径，展示价、会员价、券后价不能直接混用。应保留观察时间及来源，不把一次页面报价称为成交价。

价格规则由对应领域适配器解释；定时调度与通知只有在存在明确流程及消费者后才新增公共能力。本轮不含后台自动监控网站价格。

## 媒体与会话

人工接管目标至少 30 帧/秒。用户已选定唯一实时路径“浏览器原生标签页捕获 → WebRTC”，自动采集保留低刷新 JPEG，后续不再实现 WGC、窗口捕获等备选通道。原生路径的功能和指定采样窗口性能已有[本机验收记录](/history/2026-09-07-native-preview-validation.md)，后续重点是同一路径下的帧率波动、长时间稳定性与实际平台表现。普通 HTTP 无法使用 CaptureHandle 身份校验时明确降级低刷新；美石建工当前 HTTP 入口不应被标为实时目标已达成。见[ADR 0004](/adr/0004-native-tab-capture.md)。

继续丰富有本地响应样本支持的平台解析和清晰度信息，完善失效地址刷新与失败定位。对 blob、加密、直播等保持明确边界；不以绕过 DRM 为扩展目标。任何后备资源归属仍需内容证据或用户手选。

## 暂不纳入

本轮不包含公网部署、多任务全平台并发、任意代码编辑执行、交互式系统终端或自由叠层浮窗。扩大这些能力前需要独立说明会话所有权、隔离、权限、取消和资源回收规则。
