# 设置中心

> 文档类型：当前设置操作；依据 `SettingsCenter.tsx`、`settings.py` 与 `settings_router.py`。

设置采用“分类入口 → 子项列表 → 详情”。先选类别，再选子项，详情展示当前值、作用范围和对应操作。窄屏保持同一层级，以进入和返回代替过窄并排。

当前类别为“外观布局、浏览器预览、平台模板、数据迁移”。浏览器预览包含“预览与浏览器默认值”和“浏览器会话”；数据迁移下进入“导入旧项目资料”。

| 内容 | 入口 | 影响 |
| --- | --- | --- |
| 外观、主题、布局 | 对应设置详情 | 工作台显示和本机偏好 |
| 浏览器、会话、预览 | 浏览器相关子项 | 会话建立和画面模式；需重建时提示 |
| 网站入口、类型、模板 | 平台管理 | 网站定义和新任务能力 |
| 目标、数量、内容选择 | 采集配置栏 | 当前任务 |
| 资料与 Profile 导入 | 数据相关操作 | 显式复制，遵守覆盖与关闭限制 |

设置不暗改正在运行 worker 的状态。是否需要重建会话由会话服务决定；分类不会自动增加正文或价格执行器。Cookie 不作为普通显示偏好保存。

## 浏览器默认值

| 设置 | 默认 | 可选值 | 生效范围 |
| --- | --- | --- | --- |
| 自动切换 | 开启 | 开启 / 关闭 | 新会话初始显示偏好 |
| 低刷新目标帧率 | 1 | 1、2、5 帧/秒 | 新会话 |
| 实时目标帧率 | 60 | 10、20、30、60 帧/秒 | 新会话 |
| 默认浏览器 | Chromium | Chromium / Edge | 新会话 |

这些是配置目标，不是实测性能保证。保存于项目 SQLite `settings` 表，已有会话保留创建时快照；预览面板仍可临时选择自动、实时或低刷新。外观、导航与布局保存在当前网页浏览器的 localStorage，清理浏览器资料后恢复默认。

此前已经保存的显式值继续保留。默认值改为 60 不会暗改用户保存的 10、20、30 或已有会话；需要在此保存新值并新建会话后应用。60 是捕获与发送的配置目标，人工接管的实际验收目标仍为至少 30 帧/秒，不能把配置值当作实测吞吐。

保存失败保留输入并给出原因；返回分类或折叠导航不丢失已保存偏好，也不创建浏览器。职责见[设置架构](../architecture/settings.md)，导入见[迁移指南](../operations/migration.md)。
