# 设置中心

设置按“分类 → 子项 → 详情”组织。保留外观布局、浏览器预览、平台模板和数据迁移，新增任务默认值、下载与工具、导出与文件。

| 入口 | 详细设置 | 常见卡片覆盖 |
| --- | --- | --- |
| 浏览器预览 | 浏览器、登录态复用、页面超时、画面模式与帧率、现有会话 | 方案目标与会话来源 |
| 任务默认值 | 数量、起点、评论数、回复、选择器、等待 | 数量、课时起点、评论数、回复 |
| 下载与工具 | 引擎、路径、请求超时、重试、分片并发、清晰度、音轨 | 引擎、清晰度、音轨 |
| 导出与文件 | 默认目录、子目录、名称、格式、字段、重名策略 | 子目录、名称、格式 |

有效值按程序默认 → 项目默认 → 平台模板默认 → 卡片显式覆盖计算。卡片不保存完整默认值副本；恢复默认会删除覆盖字段。运行提交时冻结实际参数、平台定义和新会话设置，之后修改设置不影响已排队或执行的运行。现有会话保持创建时配置。

凭据由浏览器会话管理，不作为卡片覆盖字段。平台定义继续由平台注册表管理，主题和布局仅保存于当前浏览器 localStorage；项目默认值保存在 SQLite `settings` 表。

## 详情页交互

所有设置详情按功能分组，使用统一的分区标题、说明和表单网格；桌面双列，路径等长字段占整行，窄屏单列。底部操作区显示保存状态。任务、下载、导出及浏览器默认值支持撤销未保存修改；外观设置即时保存。平台编辑时单独显示编辑表单，取消后返回列表。

## 下载工具

自动模式：直接文件使用 HTTP；完整 HLS/DASH 优先使用已安装的 N_m3u8DL-RE，缺失时使用 FFmpeg；分离流与有序分片使用 FFmpeg。显式选择不支持的引擎或缺失工具会报错，不静默替换。实际引擎记录在文件详情。

工具路径沿用 `.local/tools/` 和统一安装清单，不建立第二套工具目录。“检查工具状态”显示已保存路径对应的版本与可用状态。路径修改后先保存再检查，旧路径的检查结果不会显示为新路径的状态。路径可以包含空格；参数通过结构化字段传递，不提供任意命令行。分片并发数用于 N_m3u8DL-RE，公共文件队列顺序执行。

清晰度选择用于包含对应流的清单；直接文件不转码，不存在所选清晰度时明确失败。音轨可选择默认或全部。DRM、无限直播及缺少独立解析条件的分片仍不支持。

## 导出和文件

默认输出目录留空时使用受管运行目录。设置另存目录后仍按运行分目录并登记索引；重名可自动加后缀或报告错误，均不覆盖文件。

导出字段使用逗号分隔的字段名，留空保留全部公开字段。CSV/Excel 不执行单元格公式。数据导出是单独卡片，也可用历史运行作为输入建立导出方案。

浏览器默认低刷新 1 帧/秒、实时目标 60 帧/秒；这些是配置目标，不是实测性能保证。已有会话不被默认值修改暗改。详情见[设置架构](../architecture/settings.md)和[浏览器指南](browser.md)。
