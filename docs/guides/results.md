# 结果、导出与失败重试

> 文档类型：当前操作指南
> 代码依据：`service.py`、`repository.py`、`router.py`。

## 结果、失败重试与重启

统一入口为“任务中心 → 选择任务 → 文件与结果”。默认显示该任务的文件，可以直接下载成功文件、查看内容与评论、选择视频追加下载，或导出并下载数据。基本信息、日志及任务控制也在同页详情中完成；侧栏不再单列采集结果页面。工作台右侧保留当前采集的即时结果。

历史任务没有可用浏览器会话时，已保存文件和导出不受影响；追加资源下载需要该任务仍持有会话。暂停、继续与重试沿用项目已有执行逻辑，并不表示所有网站或格式都支持从中断字节断点续传。

采集数据统一从结果区右上角“导出数据”打开，窗口底部不再常驻显示 `results.jsonl` 等文件。展开后以“采集数据 · JSONL / JSON / CSV / Excel”显示已有数据，附用途说明和下载入口；需要更新时点击“重新生成数据”，没有导出时点击“生成数据文件”。生成仍使用该任务设置的格式。视频等媒体文件在“文件”标签下载。可再次点击入口、点击收起按钮或按 Escape 收起数据导出；任务详情与工作台即时结果使用相同交互。

```text
.local/data/workbench/
  index.sqlite3             任务、事件、内容和文件索引
  tasks/<任务编号>/         每次任务的运行文件、媒体和导出
    media/                  下载完成的文件；未完成文件带 part 标识
    results.jsonl           或 results.json / results.csv / results.xlsx
  profiles/<平台>-<浏览器>/ 独立浏览器 Profile
  imports/<导入编号>/       显式导入的资料副本
  setup-cache/              校验后的工具发行包缓存
```

采集事件、内容和文件状态即时提交到项目内 SQLite。平台自身输出仍保留在任务目录；公共导出以统一字段登记身份、来源、标题、父子关系、采集时间和平台字段。JSON 导出同时包含文件清单；JSONL / CSV / Excel 以内容记录为主，文件状态可在采集结果中查看。

状态包括排队、准备、运行、等待登录、暂停中、已暂停、取消中、已取消、成功、部分成功、失败、中断。内容成功但文件失败会成为部分成功。仅文件失败时，重试只处理失败文件；存在采集失败或中断时，会重新进入适配器发现流程，按内容身份合并索引并跳过已成功文件。课程课时使用稳定身份，常见签名参数不作为媒体文件身份。已过期的签名链接仍可能需要重新采集取得新链接。

应用重启会把未完成任务（包括排队任务）标记为中断，不会自动从头重跑。检查已有文件后再选择失败项重试或新建任务。浏览器登录 Profile 独立保存，Cookie 字段不会写入任务配置和事件历史；Cookie 登录重新建任务时可能需要再次填写。

重新解析得到不同清晰度时，只有能通过完整视频身份或明确相同来源地址匹配的自动失败资源，才会替换原失败项并沿用下载额度。具体清晰度仍保留独立资源编号；原资源标记为已替换，任务事件保留替换记录。已经成功的文件、手动选定的版本及同一帖子中的其他视频不会被自动替换。

正文包含多个视频时，各视频分别登记；部分解析成功、部分仍无法解析，会保留成功输出并报告具体失败。取消任务会终止当前任务的下载并同步资源状态；暂停允许当前文件完成，但停止分派后续文件。

清除日志只清除当前显示，不删除 SQLite 中的任务历史。可恢复历史或通过带 `after` 序号的事件接口继续读取。
