# 运行、文件预览与重试

> 当前操作指南；2026-09-07。代码：`workflows/engine.py`、`results/artifacts.py`、前端 `runs/` 和 `results/`。

任务中心一行代表整次运行，显示方案名称、平台、当前步骤、步骤完成数、文件成功/失败数和创建时间。进入时不自动选中任务；点击后打开右侧详情抽屉。筛选导致任务不可见时关闭详情，空列表不保留旧详情。

详情分为“步骤、文件、数据、日志”。下载运行默认进入文件；数据采集默认进入数据。步骤显示状态和本次实际设置；文件和记录可按步骤筛选。查看详情和文件不会改写工作台草稿。

## 预览与下载

工作台区分“发现资源、任务文件、任务数据”，产物查看与任务中心共用组件，但分别管理选择和加载状态。

“发现资源”的筛选工具区按面板实际宽度排列：类型与搜索框对齐，窄面板中下载按钮换行；全选与资源监听状态显示在同一操作区。没有可下载资源时禁用全选，筛选无匹配时显示调整筛选的提示。左右平铺、最大化和手机标签模式使用同一套控件。

| 格式 | 预览方式 |
| --- | --- |
| 可播放视频、音频 | 独立播放器，优先使用已保存文件 |
| 图片 | 图片预览 |
| PDF | 浏览器 PDF 查看器 |
| TXT、JSON、JSONL、日志 | 每段最多 64 KiB，分段读取 |
| CSV、Excel（XLSX） | 分页表格，每页默认 100 行、最多 100 列 |
| 评论 | 评论文字及回复对象，保留原始记录详情 |
| 其他格式（包括旧 XLS） | 文件信息与下载入口，不执行文件内容 |

在线直接媒体通过会话下的受控接口按需读取。清单、分离流和不可独立播放的分片先下载合并；资源说明明确显示限制，不把分片伪装成完整视频。文件预览独立于网站预览，Esc 先关闭最上层文件弹窗并回到预览按钮。

访问文件使用运行 ID 与产物 ID，前端不拼接本机路径。显式另存目录也必须通过产物索引访问。已失效、无权限和不支持资源显示原因，不自动执行下载文件。

## 保存位置与恢复

默认保存到 `.local/data/workbench/tasks/<运行编号>/`，步骤拥有独立目录。详细输出位置、名称、重名策略和字段在“导出与文件”设置，卡片可覆盖子目录、名称和格式。重名不会覆盖已有文件。平台的原始输出与旧版 `results.*` 仍可读取。

运行与步骤有成功、部分成功、失败、中断、取消等状态。必要前置失败时依赖步骤显示阻止执行。应用重启把未完成运行及步骤标记中断，不自动重新执行。

“重试失败项”创建关联的新尝试，原始失败和事件保留。成功文件通过原索引复用，失败步骤重新执行；自动资源发现会重新取得链接。人工选择的会话失效时需重新发现并选择。此机制不承诺所有格式都支持字节断点续传。

旧任务通过兼容视图显示为单步骤运行，原编号、文件路径和日志保留。SQLite 升级前使用备份 API 保存包含 WAL 的一致性快照；重复启动不重复生成旧任务。
