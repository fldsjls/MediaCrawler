# 浏览器预览与人工接管

> 文档类型：当前操作；依据 `BrowserPanel.tsx`、`useBrowserPresentation.ts`、`browser.py` 与 `preview/*`。性能结论需另核对本轮联合测试。

“打开网站”建立任务可复用的 Chromium 会话。工作台显示远程画面，把鼠标、滚动、常用键、中文输入和粘贴传给同一页面。目标网站没有原生嵌入工作台，也不要求 Electron。

## 两种画面模式

| 模式 | 用途 | 行为 |
| --- | --- | --- |
| 实时交互 | 人工查看、登录与操作 | RTC 远程浏览器画面 |
| 低刷新预览 | 自动采集期间观察 | 低刷新 JPEG，减少持续编码与传输 |
| 自动选择 | 跟随控制状态 | 人工交互使用实时，自动采集使用低刷新 |

切换的是画面通道，同一浏览器、页面、登录状态和任务不变。实时模式使用浏览器原生标签页捕获，再通过 RTC 传到工作台；连接不可用时显示降级状态，使用可用的低刷新通道。帧率与响应速度取决于本机编码、页面负载和连接条件，设置目标值不是性能保证。

原生捕获必须验证页面身份。普通 HTTP 网站无法提供所需 CaptureHandle 时会明确降级；美石建工当前 HTTP 入口属于这一范围。此时可继续低刷新查看和操作，不应把降级误认为另开了浏览器。HTTPS/本机页面具备身份 API，也仍需实际连接和性能验收。

RTC 是画面，不是原生网页 DOM。浏览器系统弹窗、声音和受保护的视频不能据此视为已支持。

## 接管与继续

自动采集时只能观看。点击接管后，系统停止分派新的自动操作，等待当前操作结束并确认暂停，才开放人工输入。等待登录时可人工处理；继续采集前重新检查登录和目标。

接管不停止已登记下载；任务暂停停止分派新的采集和下载，已开始文件可完成；取消终止所属 worker 和下载进程。断线释放人工控制，不自动继续采集。

## 布局与页面

预览、日志、结果支持标签、上下或左右平铺及最大化。导航可以折叠，采集配置栏始终展开；窄屏采用抽屉和标签布局。分隔条可拖动或用方向键调整。

隐藏预览只停止画面消费，不取消任务或清空配置。新弹出页进入页面列表，切页不创建新浏览器。固定浏览器视口按面板比例显示，输入先扣除留白再换算坐标。

API 采集可能没有页面跳转。任务结束会标注完成，最后一帧不是仍在执行的证据。实现边界见[浏览器架构](../architecture/browser-workspace.md)。
