# 任务方案与采集

> 当前操作指南；2026-09-07。代码：`workflows/rules.py`、`workflows/engine.py` 和前端 `workflows/WorkflowPanel.tsx`。

## 建立方案

左侧“任务方案”保存目标、平台、资源来源和有序卡片。点击来源卡片，在弹窗中填写网址；已识别的网址匹配启用的平台，其他网页使用通用网页适配。也可以指定直接文件链接或历史运行数据。一个方案对应一个网站，可保存、另存副本、选择后再次执行。

网站类型不再是工作台公共筛选项。平台仍负责专用采集适配；支持关键词或创作者的内置平台才提供对应入口。书籍、商品与价格只有扩展契约，没有执行器，因此不提供这些任务卡片。

点击“添加下一步”，列出全部已实现卡片及可用输入；前置条件不满足或平台不支持的卡片置灰，显示后端给出的原因，不能添加。编排依据前置卡片承诺的输出，无须先运行前一步。

| 卡片 | 输入 | 作用 |
| --- | --- | --- |
| 准备浏览会话 | 网站目标 | 建立或复用会话，需要时等待人工登录 |
| 发现资源 | 浏览会话 | 使用现有课程或网页流程发现明确归属的媒体 |
| 采集内容 | 浏览会话 | 调用当前平台的内容采集器 |
| 采集评论 | 会话或内容记录 | 按平台能力采集评论及回复 |
| 下载媒体 | 发现资源或媒体直链 | HTTP、FFmpeg 或 N_m3u8DL-RE 下载 |
| 下载文件 | 资源或直接文件链接 | 保存文件，详细参数继承下载设置 |
| 导出数据 | 记录或文件清单 | JSONL、JSON、CSV 或 Excel |

典型方案：准备会话 → 发现资源 → 下载媒体 → 导出文件清单。内容采集方案：准备会话 → 采集内容 → 采集评论 → 导出数据。直接文件可以从下载开始，历史数据可以从导出开始。

## 卡片编辑

窄栏只放名称、一行摘要、启用和六点排序手柄。长文字单行省略，实际溢出时悬停约 120 毫秒或键盘聚焦显示深色提示。

点击卡片打开居中弹窗，按“基本信息”和“本卡片设置”分组；桌面使用双列字段，长路径独占一行，窄屏改为单列。标题与底部操作栏固定，表单内部滚动，弹窗高度随内容调整。底部左侧为删除卡片，右侧为取消与保存。每个参数旁显示默认或覆盖状态，默认值及“恢复默认”与对应控件对齐；“恢复默认”删除覆盖。取消不写入，未保存修改关闭时确认放弃。Esc 关闭后焦点回到原卡片。详细参数通过“前往对应设置”集中管理。

拖动六点手柄时显示浮动卡片、插入线和位置校验提示，靠近列表边缘自动滚动。也可以聚焦手柄后按空格选中、方向键调整、回车确认或 Esc 取消；不再提供上下箭头按钮。添加卡片列表的名称与来源说明同样单行省略，溢出时支持完整文字提示。

移动、禁用、删除和改变输入都会重新请求后端校验。若会破坏依赖，保留原方案并说明缺少的前置输入。独立卡片可以交换顺序，同类卡片使用独立编号。

## 运行与手动下载

“开始任务”建立独立运行并冻结参数和平台定义。保存方案不执行，修改草稿不会改变已提交运行。所有运行共用一个调度队列，默认顺序执行。

发现步骤只有一个下载消费者时，明确归属的资源即时送入下载，缩短短期链接的等待。自动流程保留数量、课时起点、选择器和等待规则；未新增任意脚本编辑器。

打开网站和播放只发现资源。在“发现资源”勾选后点“下载所选”，本次集合被固定为独立运行，后续发现不加入，当前方案不被改写；不再受旧的默认 5 个文件额度截断。

同一会话的自动操作、人工接管、暂停和恢复沿用操作屏障。前置失败阻止依赖步骤，独立步骤继续；单个文件失败不结束批次。暂停允许当前文件完成，停止后续分派。取消终止所属进程树，临时文件不登记成功。

查看运行和预览见[结果管理](results.md)，默认参数见[设置](settings.md)。
