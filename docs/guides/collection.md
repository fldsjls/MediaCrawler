# 内容采集与媒体下载

> 文档类型：当前操作指南
> 代码依据：`service.py`、`platform_worker.py`、`template_worker.py`、React 工作台。

## 一次采集

1. 在“工作台”选平台、输入方式和目标，设置内容数量、文件数量、每条内容评论数量与输出格式。界面按 `/api/platforms` 返回的实际能力提供选项。
2. 点“打开网站”，建立该平台的独立浏览器会话。链接任务打开目标；关键词任务打开平台入口。需要时先在预览完成登录。
3. 点“开始采集”，任务复用已打开的会话。没有预览会话时由任务建立。系统单任务执行，后续任务排队。
4. 在运行日志查看阶段、数量及失败信息；在采集结果查看已保存记录、下载状态，或导出文件。记录和资源即时登记，下载可与采集交错进行。

美石建工（内部标识 `meishiwang`）使用课程详情 URL。其他网站在平台管理中按类型注册，选择网页视频捕获或仅预览模板；必要时配置播放元素选择器和等待时间。历史网页 `generic` 仅保留旧任务兼容，不再作为新增网站入口。B站等内置平台保留各自声明的输入、字段和脱敏规则。平台页面或接口变化仍可能使任务失败。

三个限制互相独立：内容数量限制采集内容，文件数量限制入队媒体，每条内容评论数量限制评论。视频与图片分别控制，两者关闭或文件数为 0 时不自动下载媒体。发现总量未知时显示已处理数量，不给出估算百分比。

打开网站和播放仅把资源加入会话捕获列表，不自动下载。需要时勾选资源执行下载，可新建仅下载任务或加入已有任务。书籍、购物本轮只支持分类、配置与预览，没有正文、商品和价格执行器；仅预览模板不能开始采集，但仍可手选浏览时发现的可下载资源。自定义平台删除为禁用，内置平台由源码维护。详见[平台管理与接口](/guides/platforms.md)。

## 中间表单如何工作

中间的“目标与内容”是下一次任务的配置草稿，不是右侧网站的搜索框，也不会随输入立即采集。普通配置保存在当前浏览器的本机存储中；Cookie 与会话 ID 不随草稿保存。打开历史任务会将该任务配置回填，修改回填内容不会修改已经提交的任务。

| 区域 | 当前作用 |
| --- | --- |
| 网站类型 | 只筛选平台下拉列表，不作为任务参数；当前已选平台仍保留在列表中 |
| 平台 | 决定执行器和可用输入、评论、媒体、导出能力；切换时清空目标，重置输入方式、起始位置和下载开关等相关选项 |
| 输入方式与目标 | 指定内容、关键词搜索、创作者采集分别交给平台执行器处理；不是自动识别平台的通用输入框 |
| 内容与范围 | 内容上限、起始位置、评论开关和每条内容评论上限；起始位置的实际含义取决于平台与输入方式，课程平台显示为起始课时 |
| 视频与图片 | 控制采集时的自动下载；文件上限与内容、评论上限独立，手选下载也受文件额度限制 |
| 登录与保存 | 平台登录方式、Cookie 或播放等待时间，以及结果导出格式；实际支持项由平台能力决定 |

以 Bilibili 为例，“指定内容 / 链接”输入具体视频链接或平台支持的 ID；“关键词搜索”输入关键词；“创作者页面”输入该平台支持的创作者标识或地址。目标框中的网站首页只是占位提示，并未填入配置，也不代表首页能作为具体视频目标。部分内置平台的目标由英文逗号分隔，能否使用完整链接由各平台解析器决定；课程及自定义网站要求 HTTP / HTTPS 地址，不能把多行输入视为通用批量协议。

目前存在两条操作路径：

1. **自动采集**：填写草稿 → 可选“打开网站”并登录 → “开始采集”提交配置快照 → 后端校验平台能力与会话归属 → 任务排队 → 平台执行器采集 → 记录和媒体登记 → 下载及结果导出。无需先打开网站，任务也能创建或复用浏览器会话。
2. **浏览后手选下载**：“打开网站” → 浏览或播放发现资源 → 在结果中勾选资源下载。资源属于当前任务会话时加入该任务，否则创建仅下载任务。打开或播放本身不会自动下载。

### 整合流程前需要明确的现状

- **表单目标与浏览器地址独立**：在预览中跳转网页不会回填表单；开始采集仍以提交的表单目标为准。
- **“打开网站”复用并导航**：存在同平台空闲或任务已结束的会话时，保留浏览器和登录状态；目标改变后通过已有控制连接导航，等待导航成功或显示错误。控制权尚未开放时先请求接管，不能绕过后端控制锁。非搜索模式的 HTTP / HTTPS 目标打开第一个英文逗号前的地址；搜索模式或纯 ID 打开平台入口。
- **修改配置不改变正在执行的任务**：“开始采集”创建新任务；暂停、接管、继续与取消操作当前选中的任务，使用的是任务自身配置。
- **任务状态和草稿分别管理**：打开历史任务会回填配置。切换平台后，配置区只显示同平台任务的状态和控制按钮；原任务继续运行，日志订阅保留，可从任务中心继续控制。修改同平台草稿不会修改已经提交的任务。

当前主流程为“确定目标 → 配置采集内容 → 执行与必要时登录 → 查看结果”，保留浏览后手选下载作为另一入口。后续可增加明确的“使用当前网页作为目标”动作；目前预览中手动跳转不会自动修改采集草稿。


## 任务中心与详情

任务中心统一管理采集任务、下载文件和采集结果，不再提供独立的“采集结果”侧栏入口。进入时只显示任务列表，不自动选中任务。点击任务名称、任务行或“详情”后，在同页右侧抽屉中默认查看文件；列表、筛选与底部统计保持原位置。窄屏时抽屉占满页面宽度。

“文件与结果”提供文件、视频资源、内容、评论和失败项分类。已成功保存的文件可直接下载；导出数据后，导出文件也在当前详情中下载，不需要跳转工作台。详情顶部按状态提供暂停、继续、重试失败项和取消任务；“基本信息”和“运行日志”在详情内切换。

详情只加载所选任务的结果及其仍持有的浏览器会话资源。手选视频直接加入该任务，不创建另一任务；会话关闭或被其他任务占用后，停止提供资源追加下载，已保存文件的下载与数据导出仍然可用。失败任务可以通过重试重新解析资源，签名链接失效仍可能需要登录或重新采集。

通过关闭按钮、Escape 或点击遮罩关闭详情，焦点回到打开它的按钮。关闭、离开任务中心或任务不再匹配列表条件后，详情不保留；切换筛选不会显示上一次任务的残留信息。

查看详情不会切换工作台任务、浏览器会话或改写配置草稿。只有需要网站预览或人工登录时，在详情底部点击“前往工作台预览”，才会回填任务配置并切换页面。详情中的“清除显示”和“仅看错误”只影响该抽屉的日志显示。工作台右侧结果面板继续用于采集过程中的即时查看与未建任务的资源选择。

预览与接管见[浏览器交互](/guides/browser.md)，文件与重试见[结果管理](/guides/results.md)。
