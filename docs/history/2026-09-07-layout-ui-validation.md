## 设计对照与浏览器验收

设计依据为[三张已确认的概念稿](../assets/ui-concepts/megasync-20260907/README.md)。使用 CUA 的 Edge 浏览器接口操作实际服务，无独立 Playwright 控制通道。实现截图保存在本机 `.local/validation/megasync-ui/`，不提交任务数据截图到公共文档资产中。

检查了当前桌面视口、1536 × 1024 CSS 视口及 391 × 844 CSS 窄屏视口。浏览器保留原缩放设置，截图像素尺寸可能包含缩放产生的外围区域；尺寸判断以 `innerWidth` / `innerHeight` 为准。截图接口间歇超时，最终使用完整页面截图取得可核对的结果。

对概念稿和实际截图进行了 `view_image` 同轮检查，按本项目功能核对风格和布局：

| 项目 | 概念依据 | 实现与处理 |
| --- | --- | --- |

| 导航 | MC 标记及工作台、任务、结果、设置、关于 | 顺序保留；保留实际已有的导航折叠、窄屏抽屉和主题选择 |
| 字体 | 层次清楚的桌面工具字体 | 统一 Segoe UI / 微软雅黑 UI；修复配置标题被通用标题规则放大的问题 |
