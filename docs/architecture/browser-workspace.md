# 浏览器工作区与双模式传输

> 文档类型：当前架构；依据 `browser/preview/native.py`、`browser/preview/native_sender.js`、`browser/preview/internal.py`、`browser/preview/viewport.py`、`browser/preview/frames.py`、`browser/__init__.py` 与 `useBrowserPresentation.ts`。生产性能与真实网站验收另行记录。

## 同一会话

后端拥有 Chromium 进程、Profile、页面列表和 CDP。worker 与预览复用同一会话。实时/低刷新切换不能创建第二个浏览器、丢失登录、替换目标或重置事件游标。

画面是远程浏览器投影。输入走受控协议，固定视口与前端缩放分开，按实际显示区域换算坐标。

`browser/preview/viewport.py` 对齐真实浏览器内容区与输入坐标。原生捕获提示条会占用物理窗口，单靠 CDP 虚拟视口可能让 DOM 声称 1280×720、实际捕获却更小。该模块清除本通道的尺寸覆盖，根据实测内容区和外窗差值调整所属窗口。发送端核对实际轨道尺寸；后续尺寸变化先暂停传输，在有界时间内重新对齐并核对身份，不能恢复才关闭实时路径并明确降级，不拉伸错误画面掩盖偏移。

## 通道与生命周期

人工交互使用 RTC；自动采集使用低刷新 JPEG。自动模式根据控制状态切换。生产者与消费者各自释放资源，隐藏、关闭或反复切换不能残留编码器、重复截图任务或 RTC 连接。

自动选择在无任务、人工控制或任务结束时使用实时模式，正在自动采集时使用截图。RTC 当前仅传视频，不传音频。固定画面视口为 1280×720；设置中的帧率是请求目标而非已测得的吞吐。

新建会话的实时默认目标为 60 帧/秒，低刷新默认 1 帧/秒；旧显式设置和已创建会话保留原值。实际人工接管验收要求至少 30 帧/秒，配置目标与测量结果分别记录。

实时路径由 Chromium 原生捕获当前标签页、编码并通过 WebRTC 发送；Python 负责经过身份校验的 SDP 信令与会话生命周期。辅助发送页位于同一个 BrowserContext，复用同一浏览器，没有任务凭据，也不是另一个采集页面。它通过仅绑定 loopback 的内部服务加载，使用专属请求凭据，并限制辅助页访问范围。

标题仅用于选择候选标签页，发送前必须以 CaptureHandle 和来源核对实际捕获页面。身份在目标页的隔离执行环境中配置；不能用标题、轨道标签或“同一个浏览器”代替验证。HTTPS 和 localhost 可使用相应身份 API；普通 HTTP 无法验证时明确降级低刷新，不把所有网站强制标成安全来源。

导航使原身份失效时暂停轨道，后端重新配置并核对同一目标；复核失败则关闭对应实时连接，让前端显示降级。切换页面释放旧捕获，按新的页面重新协商。辅助页从公开页面列表、媒体候选及 Python 平台、Python 模板、Node 课程三个 worker 的目标选择中排除。

低刷新路径由 `FrameHub` 管理每个浏览器的单个 JPEG 生产者，订阅只保留最新帧，最后一个订阅离开时停止。截图服务通过 WebSocket 返回 JPEG；`browser/preview/cdp.py` 保留独立 CDP 画面能力与截图后备。旧 `browser/preview/rtc.py` 的 Python 视频转码实现保留用于回归对照，当前 `BrowserSession` 实时入口使用 `NativeRTCStreams`。两条路径均不配置外部 STUN/TURN，面向本机环境。输入继续使用独立的 Playwright 控制连接。

RTC 不可用时显示连接/降级状态，使用可用的 JPEG。美石建工当前 HTTP 入口不能被视为实时 30 帧/秒已经验收。实际帧率、延迟和 CPU 需要测量，不从传输技术推断；[路线比较](../history/2026-09-07-preview-route-comparison.md)区分独立样本与生产结果。旧截图每秒 8 帧设计值只存于[历史快照](../history/2026-09-07-jpeg-preview.md)。

画面、日志、候选资源与控制分离，丢帧或慢连接不阻塞采集和取消。重新显示面板不重建浏览器。

切换页面会更新页面 epoch，并清除旧页的排队画面。输入携带页面 epoch，后端拒绝落后于当前页面的操作，避免在旧画面上点击却作用到新页面。RTC 协商与连接有并发和有界等待；前端卸载时取消本地连接，晚到的应答仍释放服务端 peer。断连、协商失败或关闭均清理对应捕获，关闭任务不因发起它的请求取消而中止。

冷启动的等待预算分别为：客户端 ICE 收集 5 秒、后端辅助页初始化至 SDP 应答 25 秒、客户端应答请求 28 秒、客户端从 ICE 开始至首帧共 40 秒。外层等待留出前置协商和清理时间，避免仍在有效阶段预算内的请求先被客户端中止；超时仍回退低刷新，后端保留失败阶段。它们是建立连接的期限，不是帧率配置，也不表示正常连接需要等待满额。隐藏或切页立即关闭本地 peer；尚在进行的应答请求保持有界，晚到的 peer 编号用于后端清理。

## 控制权

接管先让 worker 停止分派自动操作，当前操作结束并确认暂停后开放输入；等待登录可人工处理。继续采集重新检查登录和目标，再交回自动控制。RTC 连接成功不代表取得控制权。

控制连接断开释放所属控制权，保持暂停；重连不自动恢复采集。取消与应用关闭清理所属执行和浏览器资源。

本轮是纯网页，不采用 Electron 或原生 WebView。系统弹窗、声音、受保护媒体和固定高帧率不属于默认验收结论。见[验收方法](../development/quality.md)、[ADR 0002](../adr/0002-browser-dual-mode.md)与[原生捕获决策](../adr/0004-native-tab-capture.md)。
