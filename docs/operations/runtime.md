# 启动、关闭与排查

> 文档类型：本机运维；依据统一启动脚本与会话/任务服务。

从 MediaCrawler 根目录运行 `scripts/start-workbench.ps1`，默认访问 `http://127.0.0.1:8080`。只用一个服务实例管理项目 SQLite，不使用多个 worker 写同一索引。

启动终端 Ctrl+C 关闭并清理所属进程。异常退出后任务标记中断，先检查结果再重试，不自动采集。

| 现象 | 检查和处理 |
| --- | --- |
| 端口占用 | 检查已有工作台，使用或关闭原实例，不终止无关应用 |
| 浏览器启动失败 | 环境检查与 Playwright 安装；Windows 使用统一 Proactor 启动入口 |
| 实时画面断开 | 查看连接、模式和 JPEG 降级；画面恢复不代表自动恢复采集 |
| 提示无法验证标签页身份 | 普通 HTTP 可能不支持 CaptureHandle，使用低刷新；不要通过全局安全例外掩盖此边界 |
| 能看不能点 | 检查接管、等待登录、另一窗口控制，等待暂停确认 |
| 播放无下载 | 检查资源是否仅候选、是否选中、格式能否下载 |
| 地址过期 | 可能需要重新发现链接；已成功文件不重复下载 |
| 设置未立即生效 | 核对作用域和重建提示，不强制关闭运行任务 |

性能按[质量文档](../development/quality.md)记录模式与样本。分享日志前核对敏感内容，浏览器调试地址不暴露公网。
