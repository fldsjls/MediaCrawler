# 数据与浏览器 Profile 导入

> 文档类型：运维操作
> 代码依据：`migration.py` 与设置页面。

## 显式迁移

旧项目保持原状。进入“设置 → 数据迁移 → 导入旧项目资料”，输入源文件或目录完整路径，选择类型后导入副本：

| 类型 | 行为 |
| --- | --- |
| 数据 / 下载文件归档 | 复制到独立 imports 目录，不覆盖现有任务记录，也不自动变成一次新采集结果 |
| storage_state 备份 | 校验 Playwright Cookie 数据并保存副本；本期作为备份归档，不自动激活到当前会话 |
| 浏览器 Profile | 按当前平台和浏览器类型复制到目标 Profile；目标已存在时拒绝覆盖 |

复制 Profile 前关闭所有 Chromium / Edge 浏览器与工作台会话。导入不跟随符号链接或目录联接，跳过 `.git`、`node_modules`、`.venv` 和浏览器锁文件。整个项目无需复制旧项目的虚拟环境或 node_modules；重新安装可还原依赖。
