# ADR 0002：纯网页同会话双模式

> 状态：已接受
> 日期：2026-09-07

## 背景

JPEG 适合观察采集，连续人工交互需要另一传输方式。原生桌面壳会改变交付和会话归属。

## 决策

保持纯网页，采用 RTC 实时远程交互与低刷新 JPEG，共用 Chromium。自动模式人工使用实时，采集使用低刷新，失败明确降级。切换不改变登录、任务、页面或控制权。

输入始终等待暂停屏障；画面连通不是接管许可。不引入 Electron、原生 WebView 或第三方网页直接嵌入。

## 影响与验收

验证同会话、切换释放、断线降级与坐标。性能实测，不承诺固定帧率。旧 JPEG 指标归历史，本轮性能另记。
