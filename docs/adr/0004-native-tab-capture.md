# ADR 0004：原生标签页捕获与身份校验

> 状态：已接受
> 日期：2026-09-07
> 范围：实现方向已确定，生产接入与性能验收另外记录。

## 背景

JPEG 经 Python 再编码的 RTC 路径在本机后续复测只有约 6.32 帧/秒，未达到人工接管至少 30 帧/秒的目标。浏览器原生标签页捕获独立样本约 55.94 帧/秒，为替代路径提供证据，但独立实验不是工作台生产验收。

## 决策

实时路径优先由 Chromium 原生捕获和编码已选标签页，RTC 传到纯网页工作台；自动采集仍用低刷新 JPEG，不引入 Electron 或桌面客户端。

辅助页面放在同一 BrowserContext，因为独立 context 实验无法取得有效 CaptureHandle。helper 必须从用户页面列表、媒体捕获以及 Python 平台、Python 模板、Node 课程三个 worker 的页面选择中排除。

原生路径必须验证 CaptureHandle，不能仅凭标题或媒体轨道标签放行。轨道标签不等于 CDP target ID；标题只用于寻找候选，不能替代捕获对象身份。HTTPS 或 localhost 可以使用相应身份 API；普通 HTTP 无法验证身份时明确降级低刷新，不加全局“将不安全网站当安全来源”的启动标志。

## 影响与验收

导航、切页、捕获句柄改变、协商取消和关闭都要清理对应捕获及 RTC。helper 不能成为采集目标，也不能污染资源列表。详情见后续实现对应的[浏览器架构](../architecture/browser-workspace.md)。

美石建工当前入口为 HTTP，因此不能宣称原生实时 30 帧/秒已对所有内置平台成立。需要时可另行评估窗口捕获或浏览器扩展；这些传输选项不等同于把应用改成桌面客户端，也不能自动跳过权限和捕获身份验证。
