# ADR 0001：文档信息架构

> 状态：已接受
> 日期：2026-09-07

## 背景

原站以 CLI、推广和根文件组织，新增工作台集中单页，当前能力和历史证据容易混用。

## 决策

保留 VitePress，采用任务导向的入门、使用、架构、开发、运维、历史与 ADR。每区显式索引，旧链接提供迁移提示。上游署名、许可、推广进入 about，移除 GA 和错误编辑入口。

README 定位启动，代码和现状文档说明当前事实，路线图保存未来，历史保存日期证据。结构脚本检查分区、可达、迁移和导航，构建不忽略死链。

## 影响

新增功能同步操作、职责、验收；旧数字不升级为新承诺。保留深浅、搜索、手机和键盘行为。
