# 共享 UI 边界

> 文档类型：前端开发约定。

页面拥有平台字段、设置含义、状态文案、API 和保存动作。共享 UI 只提供主题 token、控件、布局、折叠、选择、键盘、测量、焦点和反馈机制。

Workspace 处理标签、平铺、比例与最大化；设置外壳处理分类、子项、详情导航。它们接受明确数据和回调，不按平台名猜能力，不自行建任务、下载或保存网站。

深浅主题共用 token；手机保留信息层级，通过抽屉和逐级返回表达。主题、折叠或详情切换不重复建立媒体连接。成功反馈不挤压工作区，可处理错误支持关闭、Escape 和焦点返回。

至少两个真实消费者共享稳定机制时才抽取组件。页面独有比例、字段顺序和保存逻辑留在页面。验证见[质量文档](quality.md)。
